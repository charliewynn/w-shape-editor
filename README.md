# W Shape Editor

Drag-and-drop 2D outline editor for the shaped W of the clay cubic CTW identity mark (cwynn.com).

- Draggable polygon vertices, snap to 0.5 grid (toggleable)
- Mirror about the center (z=2.5), on by default — centerline vertices lock to the line
- Approximate isometric extrusion preview of the W
- Reset to the approved cubic R_V6 outline or the current 45°-foot starting outline
- Export polygon as JSON / copy to clipboard

Live editor: GitHub Pages serves `index.html` from the default branch.

## Polygon versions

- `polygon-user-v1.json` — Charlie's edited outline (2026-09-19). Validated: symmetric about z=2.5, non-self-intersecting, signed area +12.
